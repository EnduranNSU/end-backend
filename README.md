# End-Backend

Микросервисная архитектура для fitness трекера.


## Микросервисы

| Сервис | Описание | Порт | README |
|--------|----------|------|--------|
| **Auth** | Аутентификация и авторизация пользователей | 8082 | [README](auth/README.md) |
| **Training** | Управление тренировками (плановыми и выполненными) | 8080 | [README](training/README.md) |
| **Exercise** | Каталог упражнений с описаниями | 8081 | [README](exercise/README.md) |
| **Measurements** | Трекинг измерений пользователя (вес, рост и т.д.) | 8083 | [README](measuruments/README.md) |

## Технологический стек

- **Go 1.21+** - основной язык разработки
- **Gin** - HTTP фреймворк
- **PostgreSQL 15** - основная база данных
- **MinIO** - S3 совместимое хранилище для описаний упражнений
- **JWT** - аутентификация
- **Docker Compose** - оркестрация
- **SQLC** - типобезопасные SQL запросы
- **Swagger** - документация API

## Быстрый старт

### Требования

- Docker 20.10+
- Docker Compose 2.0+
- Make (опционально)
- curl, jq (для тестирования)

### Запуск всех сервисов

```bash
# Клонировать репозиторий
git clone <repository-url>
cd end-backend

# Запустить все сервисы
docker-compose up -d

# Проверить статус
docker-compose ps

# Просмотреть логи
docker-compose logs -f
